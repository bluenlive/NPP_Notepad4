# NPP_Notepad4

**NPP_Notepad4** is a Notepad++ plugin that brings essential productivity features from [Notepad4](https://github.com/zufuliu/notepad4) to the Notepad++ environment.

---

## 🛠 Features

### [English]
* **Text Alignment**: Supports Left, Right, Center, Justify, and Paragraph Alignment.
* **Math Calculation**: Calculates arithmetic expressions in the selection or current line.
* **Korean Text Support**: Provides Korean-Hanja conversion and specialized Korean text processing.
* **Web Development Tools**: Includes helpful editing utilities for HTML/CSS and web development.

### [한국어]
* **텍스트 정렬**: 좌측, 우측, 중앙 정렬 및 양쪽 정렬, 문단 정렬 기능을 지원합니다.
* **수식 계산**: 선택 영역 또는 현재 줄의 산술 수식을 계산하여 결과를 출력합니다.
* **한글 지원**: 한자 변환 및 한글 관련 텍스트 처리 기능을 제공합니다.
* **웹 개발 도구**: HTML/CSS 등 웹 개발 시 유용한 편집 보조 기능들을 포함합니다.

---

## 💻 Supported Environments

* **Operating System**: Windows 8.1 / 10 / 11
* **Architecture**: x86 / x64 / ARM64

---

## 💻 Build & Installation

### Installation
1. Download `NPP_Notepad4.dll`.
2. Copy the file to the `plugins/NPP_Notepad4/` folder in your Notepad++ directory.
3. Restart Notepad++.

### Build from Source
1. Open `NPP_Notepad4.sln` in **Visual Studio 2026**.
2. Set the configuration to **Release** | **x86** or **x64** or **ARM64**.
3. Build the solution.
